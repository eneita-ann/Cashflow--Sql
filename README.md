# Treasury Cash Flow & Liquidity Analysis (SQL)

A SQL treasury analytics project built on synthetic transaction data (5 bank accounts across 3 banks, CAD and USD, January to June 2025, about 2,550 bank transactions and 2,520 ledger entries). It reproduces core treasury reporting work: daily cash positioning, bank-to-ledger reconciliation, forecast accuracy, liquidity controls, payment controls and FX exposure.

All data is fictional and generated by `generate_data.py`.

## How to run

```bash
python3 generate_data.py   # writes CSVs to data/
python3 run_analysis.py    # loads SQLite database and runs every query
```

Requires only Python 3 (sqlite3 is built in). The SQL also runs in PostgreSQL with minor date-function changes.

## Data model

| Table | Purpose |
| --- | --- |
| `bank_accounts` | Account, bank, currency, opening balance, minimum liquidity threshold |
| `bank_transactions` | Bank-side cash movements (positive = inflow) |
| `ledger_entries` | General ledger postings for the same activity |
| `cash_forecast` | Weekly forecast net flow by account |
| `fx_rates` | Daily USD/CAD rates |

## Analyses (`sql/02_analysis.sql`)

| # | Report | SQL techniques |
| --- | --- | --- |
| 1 | Daily consolidated cash position in CAD | CTEs, running-total window function, FX join |
| 2 | Bank-to-ledger reconciliation breaks | LEFT JOIN + UNION ALL (full outer match), CASE classification |
| 3 | Weekly forecast vs actual with % error | Date bucketing, NULLIF, variance metrics |
| 4 | Minimum balance breaches by account | Window functions, threshold filtering |
| 5 | Possible duplicate payments | Self-join control test |
| 6 | Monthly inflows, outflows and MoM change | Conditional aggregation, LAG |
| 7 | USD exposure and CAD translation value | Correlated subquery, FX conversion |

## Key findings

- **Reconciliation:** 100 breaks found. 38 bank items missing from the ledger (net CAD -425.6K) are the priority, followed by 21 amount mismatches, 33 timing differences and 8 outstanding ledger items not yet cleared at the bank.
- **Forecast accuracy:** Weekly error ranged from 0.4% to 137%. Large misses clustered in weeks with small net flows, which points to the value of tracking error in dollars as well as percent.
- **Liquidity:** Operating CAD closed below its minimum balance on 6 days and Payroll CAD on 3, both first in early March, which signals a need for earlier funding transfers before payroll runs.
- **Payment controls:** 9 possible duplicate vendor payments flagged for review.
- **FX exposure:** USD exposure ranged from about 1.2M to 2.3M USD, with CAD value moving with both balances and rate changes.
